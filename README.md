<h1>Employee Salary Prediction Using Multiple ML Models</h1>
<p>
A machine learning project built using Python to predict employee salaries based on multiple features.
This project compares various regression models to identify the most accurate approach.
</p>

<div class="section">
    <h2>📌 Project Overview</h2>
    <p>
        Salary prediction is a common real-world regression problem in HR analytics.
        This project demonstrates the complete machine learning workflow, including
        data preprocessing, model training, evaluation, and prediction.
    </p>
</div>

<div class="section">
    <h2>📂 Project Structure</h2>
    <pre>
employee-salary-prediction-using-multiple-ml-models/
│
├── Employers_data.csv
├── employee_salary_prediction_using_ml.py
├── README.html
    </pre>
</div>

<div class="section">
    <h2>📊 Dataset</h2>
    <p>
        The dataset (<code>Employers_data.csv</code>) includes employee-related information such as:
    </p>
    <ul>
        <li>Experience</li>
        <li>Education</li>
        <li>Job Role</li>
        <li>Other professional attributes</li>
    </ul>
    <p><strong>Target Variable:</strong> Salary</p>
</div>

<div class="section">
    <h2>🧠 Machine Learning Models Used</h2>
    <ul>
        <li>Linear Regression</li>
        <li>Decision Tree Regressor</li>
        <li>Random Forest Regressor</li>
        <li>Support Vector Regressor (optional)</li>
    </ul>
</div>

    <h2>🚀 How to Run the Project</h2>
